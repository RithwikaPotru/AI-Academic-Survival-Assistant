# 🎓 AI Academic Survival Assistant

An AI-powered academic assistant that helps students manage their academic tasks, deadlines, and study planning.

## ✨ Features

- Add academic tasks
- Store tasks using SQLite database
- Set task type and deadline
- Set difficulty level
- Estimate required study hours
- Mark tasks as completed
- Delete tasks
- View pending and completed tasks

## 🛠️ Technologies Used

- Python
- Streamlit
- SQLite
- Git & GitHub

## ▶️ How to Run

1. Clone this repository.
2. Create and activate a Python virtual environment.
3. Install the required dependencies.
4. Run the Streamlit application.

```bash
streamlit run app.py
